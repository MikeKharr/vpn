# vpn

Личный VPN владельца: VLESS + REALITY на Xray-core, вход через порт 443
общего сервера за SNI-маршрутизатором репозитория `zpq-ai`. Клиент — Happ
на Mac и iPhone.

Решение и порядок работ — [ADR 2026-10-03-0353](agent_docs/adr/2026-10-03-0353-vless-reality-personal-vpn.md).

Репозиторий публичный: ключи, UUID, shortId, ссылки `vless://` и QR сюда
не попадают никогда.

## Что в репозитории

| Файл | Что это |
| --- | --- |
| `deploy/compose.yml` | Две службы: `render` (подстановка секретов в tmpfs) и `xray` (ядро). `ports` нет: вход приходит по сети `edge` от единицы `sni` проекта `zpq-ai`. |
| `deploy/config.template.json` | Конфиг Xray с плейсхолдерами `__ИМЯ__`: VLESS + REALITY + Vision, маска `cdn.zpq.ai`, inbound 443 с PROXY protocol и закрытый запасной 8443. `target` — алиас `zpq:443`, не `caddy:443`: под именем `caddy` в сети `edge` отвечают два Caddy. |
| `deploy/render/` | Скрипт подстановки и entrypoint службы `render`. |
| `deploy/put-secrets.sh` | Кладёт `secrets.env` на сервер скрытым вводом. Запускает владелец. |
| `deploy/secrets.env.example` | Какие значения нужны и какой они формы. |
| `deploy/host-key.pub` | Закреплённый ключ хоста для выкатки. Имя сервера — секрет, его здесь нет. |
| `bin/make-link.sh` | Собирает ссылки `vless://` и рисует QR **в терминале**. Ничего не пишет в файлы. |
| `.github/scripts/secrets-guard.sh` | Сторож: краснеет на UUID, ссылке `vless://`, ключе REALITY и изображении. |
| `test/` | Приманки сторожа и отказы рендера. |

## Порядок первой установки

Полный список шагов владельца — ADR, раздел «Ручные шаги и проверки».
Коротко и по порядку:

1. Секреты выкатки `SSH_KEY`, `SSH_HOST`, `SSH_USER` в environment
   `production` этого репозитория; публичный ключ — в `authorized_keys` на
   сервере.
2. В своём терминале: `docker run --rm ghcr.io/xtls/xray-core:26.9.30 x25519`,
   `uuidgen` дважды, `openssl rand -hex 4` дважды. Сохранить в менеджере
   паролей, никуда не вставлять.
3. `bash deploy/put-secrets.sh` — шесть значений уходят на сервер.
4. Мерж этого репозитория **первым**: контейнер встаёт в `edge` и снаружи
   недостижим. Порядок не вкусовой — без него выпуск сертификата
   `cdn.zpq.ai` по TLS-ALPN-01 падает (ADR `zpq-ai` 2026-10-03-1544).
5. Мерж PR `zpq-ai` с единицей `sni` — окно простоя 5–20 с на 443 и 80.
6. Happ по идентификатору `id6504287215`, затем `bash bin/make-link.sh mac`
   и `bash bin/make-link.sh iphone`.

## Откат

- Прежняя схема «Caddy держит 443» — `workflow_dispatch` выкатки в `zpq-ai`
  с прежним sha, 2–4 минуты.
- VPN после такого отката доступен по запасному входу 8443, но только
  после PR, который добавляет `ports: ["8443:8443"]` службе `xray`:
  по умолчанию порт закрыт намеренно (ADR, п. 1).
