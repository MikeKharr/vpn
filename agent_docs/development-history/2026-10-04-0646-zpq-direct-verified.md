# [2026-10-04] Проверка профиля «zpq direct»: доменные правила Happ работают

Файл: `agent_docs/development-history/2026-10-04-0646-zpq-direct-verified.md`

## Что проверено

Запись о выкатке ([2026-10-04-0310](2026-10-04-0310-rollout.md)) оставила
открытым: различение direct и proxy не проверено, профиль «zpq direct» принят
на веру. Со стороны сервера при TUN их не отличить, поэтому проверялся сам
механизм доменных правил на сайте, который показывает адрес клиента.

## Как

Mac, Happ подключён, Xray TUN включён. В профиле «zpq direct» → Edit rules →
Direct рядом с `domain:zpq.ai` временно добавлена строка `domain:ifconfig.me`,
переподключение. Затем дважды:

```zsh
curl -s https://ifconfig.me; curl -s https://api.ipify.org
```

## Результат

- `ifconfig.me` (в списке Direct) — адрес оператора владельца, не сервера:
  запрос ушёл мимо туннеля.
- `api.ipify.org` (вне списка, контроль) — `45.91.134.19`: туннель включён.

Оба прогона одинаковы. Доменное правило того же вида, что `domain:zpq.ai`,
применяется: `zpq.ai` и его поддомены идут напрямую, без петли через сервер.
Порядок правил в профиле — Block → Direct → Proxy, Global Proxy включён.
Временная строка после проверки убрана.

## Не проверено

- iPhone: тот же профиль на нём этим способом не проверялся.
